- Apertura en diálogo nativo dentro de la lección; cierre por botón/Escape, foco de regreso a la referencia, altura y ancho fluidos, desplazamiento vertical.
- Solicitudes reales implementadas contra la API oficial, mediante intermediario. El navegador nunca recibe la App Key. El endpoint público es /passage, en el mismo origen del Worker de pruebas; su activación depende del despliegue del archivo preparado.
- Sin endpoint o ante fallos, mensaje explícito y apertura de la alternativa existente Bible Gateway. En español esa alternativa conserva RVR1960, en inglés NIV; ambas están identificadas. No se rediseña ni se oculta la marca de Bible Gateway.
- La consulta de metadatos precede al pasaje: si la licencia se rechaza, no se consulta contenido. Se distinguen 401, 403, 404, 429 y fallos de red/servidor.
- El HTML se reconstruye con una lista permitida de etiquetas, sin scripts, enlaces, imágenes, estilos ni eventos suministrados por terceros. Se conserva texto legible y estructura de párrafos. La tipografía usa Georgia/system-ui del diseño aprobado; no se descarga ni autoaloja Untitled Serif. La fidelidad de formato final con HTML real de NVI/NIV aún necesita prueba.
- Atribución actual desde copyright o promotional_content, no una cita inventada. Si falta, no se muestra contenido. Enlace a la referencia en Bible.com.

## Arquitectura propuesta y código preparado (sin activar servicio)

PWA → GET /passage?lang=es&passage=JHN.3.16 → Worker → YouVersion.

La solución mínima propuesta es un Cloudflare Worker, conservando GitHub Pages. Workers tiene un nivel gratuito actualmente de 100.000 solicitudes por día, sujeto a límites y condiciones. No se creó cuenta ni servicio y no se contrató nada. Se explicó la solución antes de preparar el código.

- `server/youversion-worker.js`: clave exclusivamente en el secreto runtime YVP_APP_KEY. No registros de aplicación, base de datos, cuentas de estudiantes o caché persistente de Escritura.
- `server/wrangler.example.jsonc`: ejemplo inactivo con workers_dev=false. Es una configuración orientativa; no está desplegada. Elegir namespace_id no usado antes de activar.
- `server/allowed-passages.js`: solo referencias de la lección y Juan 3:16 para la prueba; no permite un proxy abierto ni URLs arbitrarias.
- CORS con lista exacta de orígenes. No es autenticación: un cliente externo puede falsificar Origin. Se requiere además el limitador de Cloudflare; falta de clave o limitador bloquea solicitudes. Límite orientativo: 60 aperturas/minuto/IP, aproximado y local a cada centro de Cloudflare; usuarios con IP compartida pueden verse limitados. No promete una cuota global estricta.
- No reenvía IP, cookies, respuestas, nombres, notas, firmas, decisiones ni cuerpos de solicitud a YouVersion. Cloudflare procesa la IP para limitar abuso; esa limitación es distinta de almacenar respuestas de estudiantes.
- Las respuestas del Worker y las solicitudes del navegador usan no-store. No hay lectura bíblica offline autorizada/implementada. La lección y las respuestas mantienen el funcionamiento local anterior.
- `src/bible-config.js`: únicamente URL pública del endpoint. Ninguna clave en frontend, build o GitHub Actions.
- Servidor fuera de dist. La rama tiene una condición adicional en el workflow de Pages: solo main puede desplegar, incluso en workflow_dispatch. No se ejecutó despliegue.
